Forny LinkedIn-adgang

Start her, når tokenet er ved at udløbe. Virker i enhver browser på enhver enhed.

Ikke en hemmelighed — den står i autorisationsadressen i forvejen. Husket i denne browser, så du kun taster den én gang per enhed. Vil du undgå det helt, så gem denne side som bogmærke med ?client_id=… i adressen.

Godkend hos LinkedIn
  1. Du lander på callbacken, som viser en code
  2. GitHub → Settings → Secrets and variables → Actions → LI_AUTH_CODE → indsæt → Save
  3. GitHub → Actions → Forny LinkedIn-token → Run workflow

Workflowet bytter koden til et token, kontrollerer at det tilhører dig, og gemmer det. Du kopierer aldrig et token.

Der er ingen hemmelighed på denne side. Client Secret findes kun i GitHub Actions Secrets og rører aldrig en browser. Tokenet gør heller ikke.
