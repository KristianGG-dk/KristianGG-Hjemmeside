Google Business Profile-adgang

Start her første gang, og hvis adgangen er tilbagekaldt eller udløbet. I daglig drift skal du ikke herind. Virker i enhver browser på enhver enhed.

Ikke en hemmelighed — den står i autorisationsadressen i forvejen. Husket i denne browser, så du kun taster den én gang per enhed. Vil du undgå det helt, så gem denne side som bogmærke med ?client_id=… i adressen.

Godkend hos Google
  1. Du lander på callbacken, som viser en code
  2. Log ind som kontakt@kristiangg.dk, og sæt flueben ved adgangen til Business Profile
  3. GitHub → Settings → Secrets and variables → Actions → GBP_AUTH_CODE → indsæt → Save
  4. GitHub → Actions → Forny Google-adgang → Run workflow → bootstrap første gang, ellers forny

Workflowet bytter koden til et refresh token, får Google til at bekræfte lokationen, og gemmer det. Du kopierer aldrig et token. Koden lever kun få minutter, så gør det med det samme.

Der er ingen hemmelighed på denne side. Client Secret findes kun i GitHub Actions Secrets og rører aldrig en browser. Tokenet gør heller ikke.
