# Pakkeafsnit

Det afsnit, der indsættes i ugens godkendelsespakke i
`publicering/pakker/`. Afledt af `fund/AAAA-UU.json` — slet det roligt og
lav det igen med `node publicering/research/vurder.mjs <uge> --skriv`.

Rådata ligger i `fund/`. Dér må der kun ligge `AAAA-UU.json`, og
`vagt-arkiv.mjs` afviser alt andet.
